# Zero Parades — Traduction Française
### Fan Translation v1.0 — par NetroIA

---

## ⚡ Installation rapide (1 clic)

1. **Double-cliquez sur `install.bat`**
2. L'installateur trouve votre jeu automatiquement
3. C'est tout. Le jeu est en français.

---

## 🎮 Activer le français dans le jeu

> ⚠️ IMPORTANT — La traduction remplace le slot "Allemand"

Dans le jeu :
**Paramètres → Langue → sélectionnez "Allemand (German)"**

Le jeu sera entièrement en **français** dès que vous validez.

---

## ❓ L'installateur ne trouve pas le jeu ?

Si votre Steam est installé dans un dossier personnalisé :

1. Ouvrez Steam → Clic droit sur Zero Parades → Propriétés
2. Fichiers locaux → Parcourir
3. Copiez le chemin qui s'ouvre jusqu'au dossier `StandaloneWindows64`
4. Relancez `install.bat` et collez ce chemin quand demandé

---

## 🔄 Désinstaller / Restaurer l'allemand

Un backup est créé automatiquement lors de l'installation :
`g5ibkj7vd...bundle.bak_allemand`

Pour restaurer l'allemand :
1. Allez dans : `Votre jeu\ZeroParades_Data\StreamingAssets\aa\StandaloneWindows64\`
2. Supprimez le fichier `.bundle`
3. Renommez `.bundle.bak_allemand` → `.bundle`
